## 2. What the rules require (the non-negotiables)

From the official rules, "Project Requirements" and "Submission Requirements":
1. Integrate the PayPal developer platform (sandbox) **and** an AI tool or model, with PayPal **central** to the project.
2. A text description of the features and functionality.
3. A working demo: a hosted URL **or** complete run instructions. A mockup or static prototype does not count.
4. A public GitHub repo with all source, plus an OSS license visible in the About section. MIT is already in place.
5. A demo video **under 3 minutes**, public on YouTube, showing the app running. No third-party trademarks or copyrighted music without permission.
6. Test access until judging ends, with any sandbox login details in the README.
7. The work must be solely the Entrant's own.

Judging is five equally weighted criteria: Technological implementation, Design, Potential impact, Innovation, Presentation (source: `paypal-hackathon/sponsor-tools.md`).

## 3. Scope cut for one person

Rule of thumb: build the **one path the video shows**, end to end, for real. Everything off that path is cut or faked honestly.

**The demo path:** open a flagship project, see the AG Grid priced from Channel3, set a budget and the tools you own, click "Build my cart", watch the agent skip owned tools and swap items with reasons, then pay with PayPal sandbox and land on the order confirmation.

| Keep (real) | Simplify | Cut |
|---|---|---|
| PayPal Orders v2 create and capture | Channel3 "DB cache" becomes a **committed JSON price cache** generated by a script. No database. | AG Charts cost breakdown (#8), unless every Keep item is green by Sun Nov 8 |
| LLM agent build-cart with tool calls | Webhook: handle and log `PAYMENT.CAPTURE.COMPLETED`; signature verification only if time allows | Draft review/moderation flow |
| Channel3 real calls for the 3 flagship projects | Recommendation drafts stored in memory, shown once, clearly flagged as drafts | Schema, migrations, Postgres (#10) |
| Recommend-a-project via LLM | The 47 former mock projects are real fixtures with authored materials, priced from the same Channel3 cache | Daily manual QA (replaced by the Playwright driver) |

Why no database: the API runs on Render with an ephemeral disk, and a database adds a service to keep alive until Dec 15. A committed price cache also protects the 20,000 Channel3 credits and makes the demo fast and repeatable. Open check: if Render's free Postgres expires before Dec 15, that settles it. Verify on Render's pricing page before reconsidering.
